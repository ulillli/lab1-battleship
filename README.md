# Морской бой на Java RMI

## Запуск

Сборка на JDK 17 из папки `battleship-rmi`.

```
.\mvnw.cmd compile
```

Запустите сервер, затем по одному клиенту для каждого игрока в отдельных терминалах.
В IntelliJ IDEA можно запустить методы `main` тех же классов.

```
java -cp target\classes battleship.GameImpl
java -cp target\classes battleship.SwingClient
java -cp target\classes battleship.SwingClient
```

Для игры по сети передайте серверу его собственный IP, а обоим клиентам — IP сервера.

```
java -cp target\classes battleship.GameImpl 192.168.1.5
java -cp target\classes battleship.SwingClient 192.168.1.5
```

Чтобы сыграть через консоль, запустите `battleship.Client` вместо `battleship.SwingClient`.
Для новой партии перезапустите сервер и оба клиента.

## Правила

Поле 10x10, корабли: 1 четырёхпалубный, 2 трёхпалубных, 3 двухпалубных, 4 однопалубных,
без касания друг друга (в том числе по диагонали), расстановка случайная.
Для выстрела щёлкните по клетке на правом поле. В консоли введите координату, например `E5`.
Тёмная клетка на своём поле — корабль, `X` — попадание, `o` — промах.
Попал - стреляешь снова, промахнулся - ход соперника.
Игра заканчивается, когда у одного из игроков потоплены все корабли.

## Как устроено

По схеме из презентации: интерфейс - реализация на сервере - реестр - клиент.

| Класс | Что делает |
|---|---|
| `Game` | удалённый интерфейс, наследует `java.rmi.Remote`, методы бросают `RemoteException` |
| `GameImpl` | реализация, наследует `UnicastRemoteObject`; в `main` создаёт реестр `LocateRegistry.createRegistry(1099)` и регистрирует объект под именем `Battleship` |
| `Client` | `LocateRegistry.getRegistry(host, 1099)`, `lookup("Battleship")`, дальше вызывает методы как обычные |
| `SwingClient` | получает прокси через тот же реестр, открывает окно игрока и выполняет RMI-вызовы в фоновом потоке |
| `BoardPanel` | рисует поле в `paintComponent()` и определяет координаты клетки по месту клика, как сетка в `CarPainter` |
| `GameState` | сериализуемый снимок двух видимых полей, текущего хода и победителя |
| `Field` | поле игрока (только на сервере): номера кораблей в клетках, сделанные выстрелы, оставшиеся палубы |

Методы `Game`:

| Метод | Что возвращает |
|---|---|
| `join()` | номер игрока 0 или 1 (-1, если мест нет) |
| `getTurn()` | чей ход (-1, пока не подключились оба) |
| `getWinner()` | номер победителя или -1 |
| `getBoards(player)` | своё поле с кораблями и поле соперника без них, текстом |
| `getState(player)` | состояние партии и две матрицы символов для графического клиента |
| `shoot(player, row, col)` | «мимо», «ранил», «убил» или «сюда уже стреляли» |

RMI передаёт числа, строки и сериализуемый `GameState` по значению. Сервер формирует
представление поля соперника со скрытыми кораблями. Графический клиент запрашивает состояние
каждые 0,5 секунды во время ожидания и сразу после своего выстрела.
Методы `GameImpl` объявлены `synchronized`, поскольку RMI может обрабатывать вызовы
двух клиентов в разных потоках.
